lark-doc-prototype-1-0：飞书文档原型 Skill 使用说明
郭寒 今天 16:40 更新 由 TRAE 创建 28 126 9 0
💡
一句话介绍
这个 Skill 用来把自然语言、截图、Figma 或结构化 JSON 转换为接近飞书文档真实体验的页面原型，适合做文档界面还原、模板预览、评审稿和工程交付前的视觉确认。
这个 Skill 能做什么

它不是生成普通网页文章，而是先把需求转换成页面契约和文档 Block JSON，再用固定的飞书文档页面结构、语义 token、图标目录和区块渲染规则生成页面。

能力 适合处理的问题 输出特点
完整文档页搭建 需要 Header、封面、目录、画布和评论区的飞书文档界面 保持 64px 顶部栏、800px 文档画布和标准页面层级
Block 级渲染 需要标题、正文、列表、分栏、表格、代码块、图片、提示块等内容 每个区块都有固定 DOM、间距和 token 样式
静态可编辑原型 需要同事直接体验编辑、目录跳转和待办勾选 支持 contenteditable、JSON 同步、目录折叠和待办状态切换
工程交付辅助 需要把设计稿或说明转成工程可理解的结构 先产出页面契约，再产出可验证的 JSON 和页面文件
适用场景
把产品说明、PRD 或知识库内容快速变成飞书文档样式的页面。
根据截图或 Figma 还原文档编辑器界面，用于视觉走查。
为模板、教程、内部分享文档制作可交互的静态预览。
把文档内容整理成结构化 Block JSON，便于后续二次渲染或工程迁移。
推荐工作流
1. 先确认页面类型：完整文档页、纯文档画布，还是嵌入式文档片段。
2. 把自然语言或截图信息转换为页面契约和 Block JSON。
3. 用校验脚本检查 Block 类型、字段和嵌套结构是否受支持。
4. 根据项目条件选择 React + UD 组件或静态 HTML 预览。
5. 运行结构、样式和文档编辑器身份检查，避免产出普通文章页。
支持的文档区块

当前版本覆盖常见文档内容块，遇到附件、图表嵌入、Slash 菜单、多用户光标等未定义行为时，不会随意模拟，需要额外来源规则。

区块类型 用途 注意事项
topTitle / h1-h3 / body 标题层级与正文段落 保持飞书文档字号、行高和 spacer 合并规则
bulletList / orderedList / todoList 要点、步骤、检查项 列表标记使用固定槽位，待办支持点击切换状态
columns 分栏排版 适合教程截图与说明文字并排展示
image 插入截图或示例图 需要明确图片来源，真实截图使用 provided
table / codeBlock / callout 对比、代码示例和提示说明 使用文档区块 DOM，不替换为普通卡片或数据看板
安装教程

下面把你提供的三张截图整理为分栏教程：左侧保留操作证据截图，右侧给出同事可以直接照做的步骤。

方式一：准备本地 Skill 包

先在本地确认 Skill 资源包已经准备好。截图中选中的文件是 lark-doc-prototype-1-0-tuned.zip，适合作为分发或上传前的安装包。

1. 打开存放 Skill 包的文件夹，确认压缩包名称和版本。
2. 如果是团队共享，建议保留 tuned 或版本号后缀，方便同事识别来源。
3. 进入 TRAE Work 的插件市场后，再执行上传或安装。
方式二：在插件市场上传

进入 TRAE Work 的插件市场，切换到“技能”页签，点击“上传技能”。弹窗会提示支持拖放或点击上传，并说明需要包含根级 SKILL.md 文件的 zip 或 .skill 文件。

1. 点击左侧导航中的“插件市场”。
2. 在顶部切换到“技能”页签。
3. 点击右上角“上传技能”，把本地安装包拖入弹窗。
4. 确认上传后，等待技能出现在列表中。
安装后确认

如果上传成功，技能会和其他 Skill 一样出现在列表中。后续同事只需要在任务中明确指定使用这个 Skill，就可以触发文档原型生成流程。

⚠️
检查点
如果上传失败，请先检查压缩包根目录是否包含 SKILL.md，以及文件是否被多包了一层目录。
这个页面里的基础交互
点击左侧目录项可以跳转到对应章节。
点击目录折叠按钮可以收起或展开目录。
直接编辑正文、标题、表格单元格和列表项，页面会同步更新内置 JSON。
点击待办复选框可以切换完成状态，并写回 Block JSON。
清空受支持文本块后按 Delete 或 Backspace，可以从画布和 JSON 中删除该块。

给同事使用前的检查
判断页面是否合格的标准不是“看起来像一篇排版漂亮的文章”，而是“看起来像飞书文档编辑器里的真实文档”。
页面包含固定 Header、封面、左侧目录和中间文档画布。
正文使用支持的文档 Block，不使用营销页卡片或普通 Markdown 包装。
安装截图已经以图片区块形式放入教程模块。
目录、待办、编辑状态和 JSON 同步交互已经接入。

建议把这份页面作为团队内介绍材料：同事先浏览能力和安装方式，再直接在页面里试编辑、折叠目录、勾选待办，理解这个 Skill 的输出边界。
